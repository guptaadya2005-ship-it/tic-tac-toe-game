# 🎮 Tic Tac Toe Game

A modern Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features

- 🎨 Modern Glassmorphism UI
- ✨ Winner Animation
- 🏆 Winning Cell Highlight
- 🔄 Restart Game
- 👥 Two Player Mode
- 📱 Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript
